# UPDATE

本書にはこのディレクトリ内の開発パッケージの更新記録を記載する。
具体的な記載方法は下記を参照する。
```
## 0.12.1

- シミュレーション時にモデル情報（provenance）を結果と同じフォルダへ出力するようにした。
  - `<単純名>.mos` — 実行した .mos スクリプト（一時ファイルでなく保存）。再実行可能。
  - `<単純名>_total.mo` — `saveTotalModel` による依存込みの自己完結モデル。
  - `<元ファイル名>.mo` — 元ソースのそのままコピー。
  - 中間ファイル削除（既定 ON）でもこれらは残す（`.mo` / `.mos` を保持対象に追加）。
```

## 0.15.0

- Activity Bar に **Modelica タブ**と **Modelica Packages ツリー**を追加した（`src/modelicaTree.js`）。
  - 表示単位はファイル/フォルダではなく Modelica の名前空間（例: `Modelica.Blocks.Sources.Sine`）。
    ルート名は `package.mo` の宣言から取るため、フォルダ `ModelicaStandardLibrary` でも `Modelica` と表示する。
  - 既存の軽量シンボル解決（`symbols.listPackageChildren` / `resolveClass`）を再利用し、`omc` は不要。
  - 項目クリックで定義ファイルを開き、ファイル内ネストクラスは定義行へジャンプする。
  - 展開時にだけ子を列挙する（初期表示で全走査しない）。ディレクトリパッケージは常に展開可、
    単一ファイルのクラスはネストクラスを持つときだけ展開可、ネストクラスは葉として扱う。
  - `**/*.mo` / `**/package.mo` の増減・編集とワークスペースフォルダ変更でツリーを自動更新
    （連続イベントはまとめて 1 回）。ツリー右上の 🔄 で手動再読み込み（ルート表も無効化）。
  - ツリー項目の右クリックから「定義を開く」「Documentation を表示」「ダイアグラムを表示」。
    これに伴い `modelica.showDocumentation` / `modelica.showDiagram` はツリー項目・エディタタイトルの
    Uri・アクティブエディタのいずれからでも対象を決められるようにした。
  - Modelica パッケージが無いワークスペースでは案内メッセージを表示する（エラーにしない）。
- `symbols.resolveContainer()` の不具合修正: `A.B.Nested`（ファイル `B.mo` 内のネストクラス）に対して
  ファイル `B.mo` 自体を返していたため、ツリーでネストクラスが自分の兄弟を無限に抱えて見えていた。
  残りセグメントがある場合は解決不能（null）を返すようにした。補完でも `A.B.Nested.` に対して
  誤った候補（`B.mo` 内の兄弟クラス）を出さなくなる。
